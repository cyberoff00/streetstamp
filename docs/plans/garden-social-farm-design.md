# Worldo 农场 · 社交偷菜 设计稿

> 状态:设计阶段(未落实)。本文件记录已拍板的机制决策,作为后续开工蓝图。
> 配套美术需求包见 `garden-social-farm-art-brief.md`。

## 1. 核心循环

> **走路 → 攒能量 & 攒种子 → 播种 → 浇水催熟 → 成熟期可被好友偷 → 收获进收藏 + 得金币 → 腾地再种**

定魂:**生长的燃料是用户真实世界的脚步**——区别于 Forest(专注计时)和原版偷菜(纯挂机)的内核。

## 2. 资源系统(四种,角色互不重叠)

| 资源 | 来源 | 用途 | 角色 |
|---|---|---|---|
| **能量** | 里程派生(每 1km = N 能量) | 浇水(推进生长阶段) | 日常走路的持续反馈 |
| **城市种子** | 每到访一个**新城市** = 1 颗(当地物种) | 播种 | 探索**广度**(多样性) |
| **里程种子** | 每累计 **50km** = 1 颗(**单趟最多计 10km**) | 播种 | 走路**总量**奖励(防刷) |
| **金币** | 收获成熟植物 + 偷取好友的 | 换装 / 花园装饰 / 买普通种子 | 经营产出与消费出口 |

规则细节:
- **能量** = 已赚(派生自里程)− 已花(持久化),夹到 ≥ 0。
- **里程种子计数器**:`counter += min(本趟距离, 10km)`,每过 50km 发一颗并减 50。10km/趟是防刷闸。
- **城市种子**给该地区物种;**里程种子**给通用物种。
- **金币**只能买**普通(里程类)种子**,**绝不卖城市/地区种子**——区域物种只能靠真到访获得,守住探索价值。
- 闭环:`走路 → 能量 → 生长 → 收获 → 金币 → 装扮/装饰`。能量进、金币出,角色不重叠。

四者定位区分:**能量=走多少 · 城市种子=去过哪 · 金币=经营产出 · 收藏图鉴=探索成就**。与现有系统不打架:等级=总活跃、avatar 换装=装扮、农场=地理广度。

## 3. 生长与地块生命周期

地块状态机:**空 → 已播种(生长中)→ 成熟 → 收获 → 空**

- **播种**:从种子库选一颗放进空地块。
- **生长**:每株若干阶段(幼苗→…→成熟),靠**浇水**推进,每次浇水花能量。
- **永不枯死**(不惩罚):不浇只是停住。
- **浇水冷却**:加轻冷却(如几小时才能再浇一次)。作用:① 偷菜节奏"过会儿再来";② 制造"成熟可偷窗口";③ 拉日活。不丢东西,不算惩罚。**社交偷菜成立的前提**。
- **地块固定数量**,**收获后腾空可再种**。收获 → 进收藏架 + 得金币。

## 4. 物种与探索绑定

- 城市种子物种 = 该城市国家/气候带真实植物(吃现成 `LifelogCountryAttributionStore` / 城市集合)。
- **收藏架 = 去过世界的植物图鉴**;集齐物种 = 走遍世界。这是农场区别于等级/换装的第三维度:**去过哪**。

## 5. 界面

- **卡片入口**(原 share 位置):只画**当前一株**(空地时画"去种一颗"提示)。点 → 花园页。
  - 现状:已放占位植物 `CompanionPlantBadge`(SF Symbol,随里程长、封顶,固定容器不超框)。待替换为真美术 + 跳转。
- **花园页**(整页):
  - 顶部:能量余额 + 金币 + 种子库数量。
  - 中部:绿色土地 + 若干地块(网格)。空地→播种;生长中→浇水;成熟→收获。
  - **收藏架**:已收获成熟植物图鉴。
  - **装饰**:用金币买摆件美化土地。
- **好友花园**:从好友列表/社交图谱进入 → 看 ta 地块 → 偷成熟的。

## 6. 社交偷菜(第二层,需要后端)

偷取规则(防"薅秃",原版偷菜最伤人的点):
- 只有**成熟态**可被偷。
- 每个好友对同一株**只能偷一次**,只能偷**一小份**(如 20% / 1 单位)。
- 单株设**总可偷上限**(如最多被偷 40%),保证主人收获时拿大头。
- 偷取给被偷者通知(复用通知 inbox:"XX 偷了你的成熟樱花"),给偷者一点金币。
- 双向:你也能偷好友的。

反作弊:后端校验成熟态、偷取次数/份额上限;能量/里程 10km 闸 + 每日上限。诚实记录:**自报 GPS 里程无法被服务器独立验证**(move-to-earn 通病),靠"偷取份额封顶 + 仅好友圈"把危害关住。

## 7. 架构(两层,边界清楚)

- **第一层 · 本地单机**(不要后端):
  - `GardenStore`(per local profile,落 `Caches/`):能量已花、种子库、地块状态、收藏、金币、已发城市种子集合、里程计数器。
  - `GardenPolicy`(纯逻辑、可 XCTest):earnedEnergy(里程)、stage(浇水)、种子发放(新城市 + 50km/10km)、金币结算。
  - 派生自 `JourneyStore` / `LifelogStore`,零后端、不碰所有权。
- **第二层 · 后端社交**:
  - 花园状态变为**后端权威、账号(`accountUserID`)所有**。⚠️ **跨过本地 scope → 云/账号 scope 的核心边界**(CLAUDE.md 强调)。本地 `GardenStore` 退化为后端状态缓存 + 乐观更新。
  - **REST 即可**(农场生长慢,无需实时,比"同行"轻):取我的/好友花园、播种、浇水、收获、偷取。
  - 复用通知 inbox 发"被偷"提醒。

## 8. 概念数据模型(非代码)

```
Garden { plots[], seedInventory[], spentEnergy, coins, collection[], grantedCitySeedKeys{}, mileageSeedCounter }
Plot   { id, state(empty|growing|mature), crop? }
Crop   { species, stage, lastWateredAt, stolenBy[](社交层) }
Seed   { species, source(city|mileage) }
Species{ id, name, regionKey, rarity, stageArt[] }
```

## 9. 待定调参旋钮(可后调,不挡设计)

1. 能量换算 & 每阶段浇水耗能数值。
2. 浇水冷却时长。
3. 地块初始数量(如 4 块)。
4. 各物种稀有度 → 收获金币数。
5. 金币定价(换装/装饰/普通种子)。
6. 偷取份额 / 单株总可偷上限 / 每日上限。

## 10. 分阶段落地

- **P1 本地单机**:四资源 + 播种/浇水/成熟/收获 + 金币 + 卡片入口 + 花园页(占位美术)。验证好不好玩、留存。
- **P2 后端社交**:花园状态后端权威化 + 好友互访 + 偷取 + 通知。
- **P3 打磨**:收藏图鉴、金币商店/装饰、换真美术。

**纪律**:P1 先用占位/AI 美术跑通,验证乐趣与留存,再为正式美术花钱。社交偷菜要不要做,取决于是否愿再面对一次后端 + 隐私 + 用户密度的成本。
