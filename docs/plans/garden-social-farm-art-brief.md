# Worldo 农场 · 美术需求包(发给设计师用)

> 用途:对接 2D 游戏插画师/美术外包时直接发送。配套机制设计见 `garden-social-farm-design.md`。
> 一句话:这是一个"用真实走路里程驱动生长"的休闲农场 + 社交偷菜玩法。

---

## 0. 你要找的人

**优先是 2D 游戏插画师**(做过 cozy / 休闲 / 农场类作品集),不是纯 UI 设计师——本玩法 80% 观感在插画。最好一人能兼顾休闲游戏 UI。

---

## 1. 风格方向

- **气质**:可爱、治愈、cozy;矢量/扁平插画或轻质感,**避免写实**。
- **参考**:开心农场/QQ农场、Stardew Valley(温暖)、Pikmin Bloom(真实世界 + 可爱)、Alto's Odyssey(柔和配色)。
- **必须与现有美术统一**:app 里已有一个**机器人 avatar**(圆润、扁平、亮色),新植物美术要能和它并排不打架。
- **配色对齐 app 主题**(以下为现用值,设计师据此取色板):
  - 卡片绿块底:`RGB(200, 232, 221)`
  - 植物绿(占位用):`RGB(41, 153, 102)` 系
  - 主题色/文字色以 `FigmaTheme` 为准(交付时附上 app 截图与色板)。
- 交付前附:**现有 app 截图(lifelog tab + avatar)+ FigmaTheme 色板**给设计师对齐。

## 2. 资产清单

### 2A. 植物(主体,工作量大头)
每个物种 = **5 个生长阶段** + 1 个"成熟可收获"高亮态:
- stage0 种子/破土 · stage1 幼苗 · stage2 成长 · stage3 接近成熟 · stage4 成熟 · (成熟高亮/可偷态)

**P1 起步集:6 个物种 × 6 图 = 36 张**(先做这套验证,别一上来做全)。建议物种组合:
- 通用类(里程种子)×3:如三叶草、向日葵、小树苗→树。
- 地区类(城市种子)×3:如樱花(日本)、棕榈(热带)、橄榄(地中海)。

**完整版**:随城市/国家扩展,目标 20–30 个物种(分批做)。

### 2B. 土地 / 地块
- 空地块、翻土(已播种)、生长中土壤、成熟态地块。
- 一片可平铺的"绿色土地"背景。

### 2C. 资源 / 图标
- 能量图标、金币图标、种子计数图标、水滴(浇水)图标。
- 通用种子袋(或每物种种子包,二期再说)。

### 2D. 动作 / 特效(可后置,P1 可用简单动效)
- 浇水水花、收获闪光、成熟"可收获"光晕、被偷特效。

### 2E. 装饰(金币商店,P1 可少量)
- 起步 6–8 件:栅栏、花盆、石径、路灯、小摆件等。

### 2F. 界面元素
- 花园页:背景、面板、按钮(播种/浇水/收获)、顶部资源条。
- **收藏架**图鉴框(含空槽位、未解锁物种剪影)。
- **好友花园**访问态 + 偷取按钮。
- **卡片入口小图**:当前植物的小尺寸版(约 44–56pt 内显示)。

## 3. 技术交付规范(iOS,务必写进合同)

- **格式**:
  - 图标/UI/矢量风:**PDF 矢量**(Figma 导出,Preserve Vector Data)。
  - 细节插画/植物:**PNG @2x + @3x**,透明背景。
- **尺寸**:植物按高清出图(如 stage4 ≥ 240px),dev 端缩放;卡片入口同一物种另出小尺寸或矢量。
- **命名约定**(直接可进 Asset Catalog):
  - `plant_<species>_stage0..4`、`plant_<species>_ripe`
  - `plot_empty` / `plot_sown` / `plot_growing` / `plot_mature`
  - `icon_energy` / `icon_coin` / `icon_seed` / `icon_water`
  - `deco_<name>`、`ui_garden_<name>`
- **动画**(如有):序列帧 sprite sheet 或 **Lottie/JSON**(说明用哪种)。
- **交付载体**:**Figma 源文件**(分组 frame + 切片)+ 导出资产包。
- **版权**:work-for-hire,资产著作权归属甲方。

---

## 4. 合作方式(省钱防坑)

1. **先付费试做一个物种**:1 物种全 6 阶段 + 1 个地块 + 1 张花园页 mock(小单)。验证**质量 + 风格匹配 + 沟通**,再扩。
2. 通过试做后,做 **P1 起步集**(§2 中标 P1 的部分)。
3. **别为未验证的玩法订全套**:P1 可先用占位/AI 图跑通玩法与留存,确认好玩再请设计师做正式美术。
4. **完整 20–30 物种分批**:按城市/国家上线节奏逐步补,不一次买断。

---

## 5. P1 最小美术集(只做这些就能跑通单机)

- 6 物种 × 6 图(§2A 起步集)
- 4 个地块态(§2B)
- 4 个资源图标 + 1 种子袋(§2C)
- 花园页基础 UI + 收藏架框(§2F)
- 卡片入口小图(§2F)

> 社交偷菜(好友花园/偷取特效)、装饰商店、完整物种库 = P2/P3,**先不做**。
